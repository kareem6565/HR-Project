🧩 طيب LangChain فين؟

ما تخليش المشروع كله:

LangChain Agent → LangChain Agent → LangChain Agent

LangChain نستخدمه كـbuilding blocks.

مثلاً:

LangChain
│
├── LLM
├── Prompt
├── Structured Output
├── Document Loaders
├── Embeddings
├── Vector Store
├── Tools
└── Retrieval

و:

LangGraph
│
├── Job Agent
├── Resume Agent
├── Matching Agent
├── Evaluation Agent
├── Interview Agent
└── Communication Agent

يعني:

LangChain = أدوات

LangGraph = orchestration

Agents = workers

FastAPI = application backend
